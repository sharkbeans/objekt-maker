# Objektify - Custom Photocard Maker

A web-based tool for creating custom photocards with beautiful borders, text, logos, and QR codes. Perfect for creating Objekt cards and other photocard formats.

## Features

### Front Side Customization
- **Image Upload & Adjustment**
  - Upload JPG or PNG images (max 5MB)
  - Zoom and pan controls for precise image positioning
  - Real-time preview of your design

- **Border Options**
  - Toggle Objekt-style colored border on/off
  - Overflow border effect with adjustable size
  - Choose from preset color categories
  - Custom color selection with hex input
  - Upload custom border images to replace the colored border
  - Supports multiple border styles and colors

- **Text Customization**
  - Add top text (e.g., artist name)
  - Add middle text (e.g., card number)
  - Add bottom text (e.g., additional info)
  - Adjustable font styles, sizes, and colors
  - Text positioning controls

- **Logo on Front**
  - Upload custom logo image
  - Zoom and position controls
  - Rotation adjustment

### Back Side Design
- **Signature Area**
  - Upload signature image
  - Position and zoom adjustments
  - Dedicated signature modal for precise control

- **Top Logo**
  - Add custom logo/graphic at the top
  - Zoom and positioning controls
  - Rotation adjustment

- **Back Side Logo**
  - Add logo/graphic in the bottom text area
  - Full zoom and position control
  - Rotation options

- **QR Code Generation**
  - Automatic QR code generation
  - Custom QR code support
  - Positioned in the bottom right corner

### Card Size Options
- **Preset Sizes**
  - Objekt Default (65×100mm)
  - Standard Photocard (54×86mm)
  - Credit Card (55×85mm)
  - Instax Mini (57×89mm)

- **Custom Sizes**
  - Input custom dimensions in millimeters
  - Automatic pixel conversion at 300 DPI

### Export & Download
- **High-Quality Export**
  - Download front side design
  - Download back side design separately
  - 300 DPI resolution for professional printing

### Presets & Settings
- **Save/Load Presets**
  - Save your design settings for later
  - Load previously saved presets
  - Save multiple variations of your design
  - Note: Images must be re-uploaded after loading presets

### User Interface
- **Responsive Design**
  - Desktop and mobile optimized
  - Toggle between front and back side views
  - Collapsible control sections for cleaner UI
  - Real-time canvas preview

- **Mobile Support**
  - Mobile-friendly controls
  - Separate back side section on mobile
  - Touch-optimized sliders and inputs
  - Menu toggle for compact mobile layout

### Technical Features
- **Real-Time Rendering**
  - Live preview of all adjustments
  - No lag or delay in visual feedback

- **Non-Destructive Editing**
  - All adjustments are reversible
  - Original image quality preserved

- **Modern Web Stack**
  - Pure HTML/CSS/JavaScript (no dependencies)
  - Lucide icons for clean UI
  - QR Code generation library included
